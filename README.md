# SpatialSense AR 🌐✨

> An AI-driven spatial analysis and augmented reality (AR) environment simulator built with Python and Streamlit.

---

## 📌 Project Overview

**SpatialSense AR** is an interactive spatial intelligence tool designed to bridge the gap between 3D environmental data and computer vision applications. Built as a lightweight, performant prototype, it enables developers and users to visualize spatial mapping concepts, analyze object threads, and interact with real-time AR layout configurations.

---

## ✨ Key Features

* **3D & Spatial Analytics:** Process real-time environmental vectors and spatial layout parameters.
* **Streamlit-Powered Interface:** Clean, reactive dark-mode user interface for smooth telemetry monitoring.
* **Thread & Memory Optimization:** Efficient Python architecture designed to minimize latency during spatial object rendering.
* **Modular Codebase:** Standardized structure allowing seamless expansion for computer vision libraries (OpenCV, PyOpenGL).

## 🛠️ Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed on your system.

python --version

### Installation

1. **Clone the repository:**
   git clone [https://github.com/priyanshi-thakur/spatiansense-ar-project.git](https://github.com/priyanshi-thakur/spatiansense-ar-project.git)
   cd spatiansense-ar-project

2. **Create a virtual environment (optional but recommended):**
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate

3. **Install dependencies:**
   pip install -r requirements.txt

### Running the Application

Launch the Streamlit web server:

streamlit run app.py

The app will open automatically in your browser at `http://localhost:8501`.
